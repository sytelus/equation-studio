START HERE
Think in fields. Build in layers.
01 / Read the construction
The Pipeline tab shows every component in order with a live picture of what it produces. Click a card, or press [ ], to show that stage on the canvas. What it changes shows exactly which pixels a component affects. Hover any control for an explanation.
02 / Understand a component
The inspector typesets the component’s equation and lists every symbol with its live value. Each parameter says what it does; ▦ renders the image across its whole range. With Rulers on, the crosshair reads raw field values under the cursor.
03 / Experiment safely
Every parameter has ↺ reset, and a marker shows its original value. ✦ Variations suggests nearby versions; hover to preview. Hold ◐ Original (or O) to compare, ⟲ Revert to start over; Undo always works. Untick a component to bypass it.
04 / Compose
Drag components from the library onto the graph or onto an input dot. Drag between dots to wire. ＋ on an input inserts a modifier (a warp, tint or mask) in place; Replace with… swaps a component while keeping its wiring. Custom equations are typeset live as you type.
Is the image live? Yes. The canvas is computed on your GPU from the equations every time anything changes; the LIVE GPU badge pulses on each frame. Only the small scene thumbnails in the library are saved pictures. The nebula ports the supplied equations to GPU float32; the other scenes are original interpretations, not recovered artist formulas. See Research & provenance.

Canvas: drag to pan, wheel or pinch to zoom about the cursor, click to pin a reading, Alt-click for a one-off raw value. A saved JSON contains the graph, colors, parameters, camera and keys. Reference images and snapshots stay in this browser.
