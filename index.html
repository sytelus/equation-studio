START HERE
Think in fields. Build in layers.
01 / Investigate
Open a scene. Select a graph component, then choose Isolate to see the coordinates, scalar field, geometry or emitted light it contributes. Inspect its equation and input connections.
02 / Compose
Add components from the library. Click an output dot and a compatible input dot to wire them. Input menus provide the same controls without dragging. Use Set as output to choose the final image.
03 / Animate
Click ◆ beside a numerical parameter to create a key. Move the playhead and adjust that parameter to add another key. Use smooth, linear or hold interpolation. Built-in flow-speed parameters also use time directly.
04 / Author
Add a custom scalar, coordinate or color equation. Write a GLSL expression using p, x, y, r, theta, t, a, b. Apply compiles it; errors leave the last good image visible. Save projects as editable JSON.
Know what you are seeing. The nebula ports the supplied equations to GPU float32; the other subject studies are original procedural interpretations, not recovered artist formulas or physical simulations. Open Research & provenance for the evidence ledger.
Space: play/pause · Ctrl/⌘ Z: undo · Ctrl/⌘ Shift Z: redo · Ctrl/⌘ S: save · Escape: cancel a connection or exit isolation. Canvas: drag to pan, wheel to zoom, Fit to reset. The component library and inspector also work without a mouse.
A saved JSON contains the graph, colors, numerical parameters, view and animation keys. A comparison image is local, temporary, and never exported or uploaded. The full archive contains the CPU oracle and detailed source/API/research guides.
