START HERE
Think in fields. Build in layers.
01 / Investigate
Open a scene. Select a graph component, then choose Isolate to see the coordinates, scalar field, geometry or emitted light it contributes, or Contribution to see exactly which output pixels it changes. Turn on Previews to watch every component at once, and Rulers for coordinates, pixel values and raw field numbers under the cursor.
02 / Compose
Drag components from the library onto the graph, or onto an input dot to wire them immediately. Drag between dots to connect, or drag a wire off an input to disconnect. Input menus provide the same controls without dragging. Use Set as output to choose the final image.
03 / Animate
Click ◆ beside a numerical parameter to create a key. Move the playhead and adjust that parameter to add another key. Drag keys along their lane to retime them. Use smooth, linear or hold interpolation. Built-in flow-speed parameters also use time directly.
04 / Author
Add a custom scalar, coordinate or color equation. Write a GLSL expression using p, x, y, r, theta, t, a, b and the helper menu. Apply compiles it; errors leave the last good image visible. Take a Snapshot before a risky change and return to it from the library.
Know what you are seeing. The nebula ports the supplied equations to GPU float32; the other subject studies are original procedural interpretations, not recovered artist formulas or physical simulations. Open Research & provenance for the evidence ledger.
Keys: Space play/pause · Home/End start/end · , and . step one frame · Ctrl/⌘ Z undo · Ctrl/⌘ Shift Z redo · Ctrl/⌘ S save · Ctrl/⌘ D duplicate · Delete removes the selected component while the graph has focus · I isolate · C contribution · P previews · R rulers · G grid · F fit · S snapshot · L locate · Escape cancels a connection, unpins a probe, or returns to the composite.
Canvas: drag to pan, wheel or pinch to zoom about the cursor, Alt-click for a one-off raw probe. A saved JSON contains the graph, colors, numerical parameters, view and animation keys. Comparison images and snapshots stay in this browser and are never exported or uploaded.
