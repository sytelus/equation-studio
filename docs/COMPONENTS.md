## Image coordinates

ID: `coordinates` · **coord** · Coordinates

World-space coordinates. Native 2000 × 1200 sampling keeps the original +1/840 offset on each axis. All image layers share this field.

**Expression / role:** p = (pixel − center) × worldUnitsPerPixel

No parameters.
