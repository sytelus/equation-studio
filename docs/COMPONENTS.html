Image coordinates

ID: coordinates · coord · Coordinates

World-space coordinates. Native 2000 × 1200 sampling keeps the original +1/840 offset on each axis. All image layers share this field.

Expression / role: p = (pixel − center) × worldUnitsPerPixel

No parameters.

Translate · rotate · scale

ID: transform · coord · Coordinates

Inverse-map world pixels into local object coordinates. This moves the object without stretching a stored picture.

Expression / role: q = R(−angle) (p − center) / scale

Parameter Kind Default Allowed interval Intent
x number 0 -5 to 5, control step 0.01 Center X
y number 0 -5 to 5, control step 0.01 Center Y
angle number 0 -6.28 to 6.28, control step 0.01 Rotation
scale number 1 0.05 to 5, control step 0.01 Scale
stretch number 1 0.1 to 4, control step 0.01 Vertical stretch
